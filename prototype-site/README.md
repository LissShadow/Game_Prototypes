# Игровые прототипы Ольги Мастепан — сайт-обёртка

Одностраничный каталог с тёмным стеклянным оформлением, локальным вариативным шрифтом Manrope и запуском игр внутри страницы. Подключён Book Tamer v0.65; файл самой игры не изменён.

## RU / EN

Переключатель расположен в шапке каталога и панели открытой игры. Переводятся заголовки, контактная строка, карточки, жанры/теги, счётчик, свободная ячейка, подписи, сообщения, загрузка, метаданные страницы и доступные названия кнопок. Выбор сохраняется отдельно в `localStorage['olga-prototypes-language']`. По умолчанию — русский; при недоступном хранилище переключение работает в текущем сеансе.

Язык сайта не меняет язык уже открытой игры, её сохранения или состояние. Iframe не перезагружается. Языки, поддерживаемые самой игрой, показаны на обложке. Если будущий прототип имеет отдельные RU/EN-сборки, можно указать их в `files`: выбор применяется при следующем запуске карточки.

## Готовый сайт

`../index.html` — автономный каталог: CSS, JavaScript, словари, шрифт с OFL-лицензией и обложки уже встроены. CDN и внешние библиотеки не нужны. Рядом используется существующий `../Book-Tamer.html`.

Для минимального локального запуска держите `index.html` и `Book-Tamer.html` рядом. Для статического сервера выполните из родительской папки `python -m http.server 8001`. В Arena для запуска вложенной игры используйте живой предпросмотр, а не ограниченный файловый просмотрщик.

## Подключение новых HTML-игр

Полная инструкция: **[ADDING_PROTOTYPES.md](ADDING_PROTOTYPES.md)**.

Два варианта:

1. `python prototype-site/add_prototype.py ...` — помощник копирует автономный HTML и обложку, создаёт двуязычную запись и пересобирает каталог; есть безопасный `--dry-run`.
2. Вручную разместить игру в `games/ID/index.html`, обложку в `prototype-site/assets/`, добавить объект в `prototypes.json` и выполнить сборку.

`prototypes.json` хранит постоянные id, RU/EN-названия и описания, теги, версию, обложку, путь к игре и её поддерживаемые языки. `files.ru`/`files.en` — необязательные отдельные сборки. Проверка отклоняет дубли id, некорректные локализации и небезопасные пути.

Посетители не могут загружать файлы: импорт выполняет автор локально. Это статический сайт, а не публичный файловый хостинг или административная панель.

## Исходники

- `index.template.html` — разметка;
- `style.css` — оформление и адаптация;
- `app.js` — переключение языка, карточки, iframe, история и fullscreen;
- `locales.json` — все тексты самого сайта на русском и английском;
- `prototypes.json` — реестр игр и двуязычные метаданные;
- `catalog_schema.py` — общая проверка реестра для сборки/импорта/публикации;
- `add_prototype.py` — импорт автономных HTML;
- `assets/` — шрифт, лицензия и оптимизированные обложки;
- `build.py` — автономный готовый каталог;
- `prepare_pages.py` — публикационный артефакт только с зарегистрированными играми;
- `tests/` — регрессии.

Обычная сборка не требует npm или сторонних Python-пакетов, только Python 3.10+:

```sh
python prototype-site/build.py
python prototype-site/tests/pages.py
python prototype-site/tests/import_prototype.py
```

Команды выполняются из корня проекта. `prepare_pages.py --output _site` требует пустую папку вывода; существующие файлы не удаляются.

## GitHub Pages

Настроенный `.github/workflows/pages.yml` по push в `main` пересобирает каталог и публикует основной HTML, зарегистрированные игры и все указанные языковые варианты. Папки `games/ID/`, отсутствующие в реестре, не копируются. Для многофайловой игры папка публикуется с её ресурсами, поэтому не храните в ней приватные/нужные только разработчику файлы. Исходники сайта и тесты не попадают в артефакт.

Инструкция по первой публикации: `../README.md`. В Settings → Pages выберите Source → GitHub Actions. Пути относительные, сайт поддерживает адрес `/repository/`. GitHub-публикация из этого окружения не выполнялась.

## Проверки

- `tests/site.cjs`: исходный сценарий сайта, настоящий запуск Book Tamer, возврат, история, фокус/inert, 4 размера, reduced-motion, file://, отсутствие JS-ошибок.
- `tests/language.cjs`: RU/EN всего интерфейса, метаданные/ARIA, сохранение языка, 4 размера, смена языка в живой игре без перезагрузки/изменения её состояния, обновлённый фокус, отдельные RU/EN HTML будущей игры, счётчик/пустая карточка, запрет localStorage, file://.
- `tests/pages.py`: чистый артефакт, неизменный оригинал игры, будущие ресурсы, HTTP по подпути репозитория, проверка `.gitignore` и путей.
- `tests/import_prototype.py`: dry-run, копирование HTML, двуязычные метаданные, дубли, языковые сборки, исключение незарегистрированных игр, откат ошибки, неверный реестр.

Для браузерных тестов временно установите Playwright и Chromium в этой папке, поднимите родительский HTTP-сервер на 8001, затем выполните `node tests/site.cjs` и `node tests/language.cjs`. В финальном проекте временные зависимости и скриншоты удалены. Desktop/mobile RU/EN визуально просмотрены.
